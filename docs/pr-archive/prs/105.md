### 판정 (`eligibility/rule/benefit/BenefitJudge`, 순수 자바)
조건 약속표(`benefit-condition-types.draft.md`) 그대로: 같은 group은 "또는", 다른 group은 "그리고". 하나라도 불충족 → 지원 불가, 모두 충족 → 지원 가능, 그 밖 → 확인 필요.

| type | 판정 |
|---|---|
| AGE | 출생 연월로 기준일 만 나이 (생일 달이면 확인 필요) |
| MARITAL · NEWLYWED_YEARS | 혼인 상태, 신혼은 혼인 연월로 (기본 7년) |
| CHILDREN | 자녀 수 (막내 나이 조건은 확인 필요) |
| HOUSEHOLD_TYPE | 1인 가구·한부모·다자녀만, 나머지 확인 필요 |
| WELFARE_STATUS | 수급 여부 |
| INCOME_MEDIAN_PCT | 가구 소득 % 구간 그대로 비교, 본인 소득은 1인 기준으로 바꿔 비교. 걸치면 "구간 경계라 확인이 필요해요" |
| INCOME_AMOUNT | % 구간 × 기준중위소득 → 연 금액 구간 |
| ASSET_AMOUNT | 총자산·자동차 구간 (그 밖 kind는 확인 필요) |
| HOMELESS · HOMELESS_YEARS | 집 여부·무주택 기간 구간 |
| RESIDENCE | 사는 곳이 그 지역이면 충족, 아니면 확인 필요 "이 지역으로 이사하면 받을 수 있어요" (지원 불가로 떨어뜨리지 않아요) |
| MOVE_IN | 확인 필요 "전입하면 받을 수 있어요" |
| 그 밖(취업·학력·임차 조건 등), known=false, OTHER | 확인 필요 |
| EXCLUSIVE · PRIORITY | 판정하지 않고 안내(notes)로 |

- 사람 확인 전 정책(`needsReview`)은 지원 가능 → 확인 필요로 낮추고 이유를 줘요

### API (no-store, 판정 입력 저장 안 함)
- `POST /api/v1/benefits/search`: `filters.regionCodes`(찾아볼 지역, 비우면 전체 · 있으면 전국 + 그 지역), `filters.categories`, `applicant`(구간 값), `sort` RECOMMENDED·DEADLINE·AMOUNT, 커서
  - `summary{eligible, needsInput, ineligible, annualAmountWon}`, `categoryCounts`, items(제목·기관·분야·지원 내용 한 줄·1년 금액·신청 상태·D-day·판정·준비할 돈 반영 여부·검수 전)
  - 지원 불가는 목록에서 빼고 개수만
  - 1년에 받을 수 있는 돈: 지원 가능만, 금액이 정해진 지원만(대출 제외), 월 지원은 최대 12개월
- `POST /api/v1/benefits/{id}/evaluate`: 그룹별 조건 결과(공고 판정과 같은 Item 모양), 안내(notes), 1년 금액. 없거나 숨긴 혜택은 404
