### 무엇을
운영 `/homes` 「지도로 보기」에서 마커가 하나도 안 나오고 「공고 위치를 불러오지 못했어요」가 떠요.

- 원인:
  - 화면은 늘 `tenure`(`RENT`·`BUY`)를 붙여 `GET /api/v1/notices/map`을 불러요.
  - 지도는 공고마다 `NoticeListFilter.BUY_TYPES.contains(s.noticeType())`로 걸러요.
  - `BUY_TYPES`는 `List.of(...)`라 `contains(null)`이 `NullPointerException`을 던져요.
  - 운영에는 공고 종류가 빈 공고(예: 희망하우징 공공기숙사)가 있어서, 지도 API가 500이에요.
- 재현(운영, 읽기 요청):
  - `…/api/v1/notices/map?swLat=37.42&swLng=126.76&neLat=37.70&neLng=127.18&zoom=11` → 200
  - 같은 주소에 `&tenure=RENT` 또는 `&tenure=BUY` → 500 `INTERNAL_ERROR`
- 고침: 종류가 비면 분양이 아니라 임대로 봐요. 목록 검색 SQL(`notice_type is null or not in (분양)`)과 같은 규칙이에요.

### 테스트
- `NoticeMapClusterTest.noticeWithoutATypeIsShownAsRentAndDoesNotBreakTheMap`: 종류 없는 공고가 RENT 지도에는 나오고 BUY에는 안 나와요. 고치기 전 코드에서는 `NullPointerException`으로 실패하는 것을 확인했어요.
