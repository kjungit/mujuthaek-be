### 알림 (개발 서버, 2026-10-30 아침)
- `[dev api] NOTICE_COLLECTOR_UNAVAILABLE GET /api/admin/sources` (10분에 10번 넘게)
  - 개발 서버에는 원래 수집기가 없어요(README 「서비스 사이 연결」).
  - 관리자 「수집 현황」 화면이 1분마다 다시 물어서 503이 늘 나는 게 정상인데, 그때마다 알림이 갔어요.
- `[dev api] 처리하지 못한 오류 GET /api/v1/notices/…/chat/stream AsyncRequestNotUsableException`
  - 채팅 실시간 연결(SSE)을 사용자가 먼저 끊었어요(탭 닫기·화면 이동).
  - 그 뒤 서버가 보내려다 난 예외인데, 「처리하지 못한 오류」(500)로 잡혀 알림이 갔어요.

### 고친 것
- `GlobalExceptionHandler`
  - `AsyncRequestNotUsableException`을 따로 받아요. 응답할 곳이 없으니 응답 없이 debug 로그만 남기고 알리지 않아요.
- `mujuthaek.ops-alert.ignore-codes`(`OPS_ALERT_IGNORE_CODES`, 쉼표로)를 더했어요.
  - 그 환경에서 늘 나는 게 정상인 오류 코드는 5xx여도 알리지 않아요.
  - `compose.dev.yml`의 api에 `OPS_ALERT_IGNORE_CODES: NOTICE_COLLECTOR_UNAVAILABLE`을 넣었어요.
  - 운영은 수집기가 있어서 그대로 알려요.

### 확인
- `GlobalExceptionAlertTest`
  - 채팅 연결 끊김은 알리지 않아요.
  - `NOTICE_COLLECTOR_UNAVAILABLE`은 무시하고, `NOTICE_REVIEW_UNAVAILABLE`은 그대로 알려요.
- `OpsAlertTest`: 무시할 코드 설정, 기본값은 빈 목록
- `docker compose config`(dev)에 환경 값이 들어가요.
