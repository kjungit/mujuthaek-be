### 왜
운영 서버에 테스트 6종(스모크·부하·내구·스트레스·한계 찾기·스파이크)을 돌리고, 고친 뒤 같은 조건으로 다시 재서 비교하려고 해요. 비교하려면 개선 전 결과(숫자·그래프 이미지·느린 쿼리·버전·데이터 양)를 매번 같은 모양으로 남겨야 해서 스크립트로 모아요.

### 구성 (노트북에서만 돌아요)
- **k6** (`perf/k6`): EC2 nginx로 직접(Vercel 안 거침)
  - 흐름: 둘러보기 60% · 조건 넣고 판정 25% · 로그인 사용자 15%, 행동 사이 3~5초
  - API 종류 태그와 p95/p99 합격 기준: 조회 200/500ms, 목록·검색 500ms/1s, 판정 1s/2s
  - 테스트별 부하: 스모크 2명 1분, 부하 100명 15분, 내구 50명 1시간, 스트레스 50→1,000명(단계 3분, 기준 넘으면 멈춤), 한계 찾기 초당 20건부터 2분마다 +20건, 스파이크 20→500→20명
  - 로그인 흐름: 운영 `JWT_SECRET`으로 테스트 계정 토큰을 직접 서명(HS256, `iss=mujuthaek-api`). 운영 코드 변경 없음, 비밀 값은 `perf/.env`(커밋 안 됨)에만. 비우면 판정 흐름으로 돌려요
  - 테스트 데이터(`data.json`): 운영에서 한 번 뽑은 지역 코드·공고 id + 가짜 지원자 조건 4벌. 전후 비교를 위해 다시 뽑지 않아요
- **Prometheus·Grafana(3300)·이미지 렌더러** (`perf/docker-compose.yml`): 서버 지표는 `tunnel.sh` SSH 터널로 읽어요. 대시보드 15패널(k6 p95·p99·RPS·에러율, 서버 API별 p95·p99, CPU·steal, 컨테이너, 힙, GC, Hikari)
- **`run.sh <test> [메모]`**: 결과 폴더 `perf/results/<시각>_<test>_<api 버전>/`(커밋 안 됨)에
  - `meta.json`(시각·버전·메모·스크립트 커밋·data.json 해시), k6 `summary.json`·html 리포트
  - `server_by_uri.csv`, `server_summary.json`, `stages.csv`(스트레스·한계 찾기 단계별)
  - Grafana 패널 PNG, CloudWatch(EC2 크레딧, RDS CPU·커넥션) PNG·JSON
  - `slow_queries.csv`(pg_stat_statements 전후 차이), `table_counts.csv`(데이터 양)
- **`compare.sh <전> <후>`**: 전후 비교 마크다운 표(종류별 p95·p99, RPS, 에러율, 서버 지표, API별 p95, 느린 쿼리)
- `server.sh`: exporter 켜기·끄기, 서버 버전, pg_stat_statements 확인(서버 안에서 psql)

### 일부러 뺀 것
- `/api/auth/refresh`: refresh 토큰이 HttpOnly 쿠키라 부르면 테스트 계정 로그인이 돌아가며 바뀌어요
- 외부 API를 부르는 기능(주소 좌표, AI 추출), 관리자 API
- 관심 등록은 등록 직후 해제해서 운영 DB에 남지 않아요
