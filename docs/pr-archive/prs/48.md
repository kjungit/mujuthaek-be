### 무엇을
공통 코드인 시·도와 시·군·구 코드표, 그리고 그걸 주는 API예요. (REST 스택 2/7, [#47](47.md) 위에 쌓음)

- 테이블 `common.regions` (`V202610220255__common_regions.sql`): 코드(2자리 시도 / 5자리 시군구), 이름(`마포구`), 전체 이름(`서울특별시 마포구`), 시도 짧은 이름(`서울`), 상위 시도, `valid`(폐지면 false), `replaced_by`(바뀐 코드), 기준일. 코드 모양과 "시군구는 시도가 있어야 함"은 DB에서 막아요
- 적재 `common/region/RegionLoader`: 행정안전부 **법정동코드 전체자료**(탭 구분 `법정동코드 · 법정동명 · 폐지여부`, CP949)에서 시도(뒤 8자리 0)·시군구(뒤 5자리 0)만 골라 넣어요
  - 폐지된 코드는 지우지 않고 `valid = false`, 같은 시도(짧은 이름) 안에 이름이 같은 유효 코드가 있으면 `replaced_by`로 이어요 (강원도 42 → 강원특별자치도 51, 강원도 춘천시 42110 → 51110)
  - 같은 파일을 다시 넣어도 결과가 같아요
  - 실행: `./gradlew bootRun --args='--mujuthaek.regions.load-file=<파일> --mujuthaek.regions.base-date=2026-07-01'`
- API (`RegionController`, 로그인 없이)
  - `GET /api/v1/regions` → `{ baseDate, sidos: [{ code, name, shortName, sigungus: [{ code, name }] }] }` (유효한 코드만). `Cache-Control: public, max-age=86400` + `ETag`, 같은 ETag면 304
  - `GET /api/v1/regions/{regionCode}` → `{ code, level, name, fullName, valid, replacedBy, validTo }`. 2·5자리가 아니면 400 `VALIDATION_FAILED`, 없으면 404 `NOT_FOUND`
- `RegionQueryService.displayName(code)`: 다른 모듈이 응답에 붙일 `regionName` ("서울 마포구")

### 왜
- 조건 입력의 사는 곳, 공고 목록의 지역 필터, 관심 지역이 모두 이 코드표를 써요. 공고·혜택 응답의 `regionName`도 여기서 붙여요.
- 코드표는 해마다 몇 번 바뀌어서 마이그레이션에 값을 박지 않고, 원본 파일을 받을 때 넣게 했어요.
- **아직 실제 데이터는 없어요.** 법정동코드 전체자료 최신판(code.go.kr)을 받아 위 명령으로 한 번 넣어야 해요. 받기 전에는 `GET /regions`가 빈 목록이에요.
