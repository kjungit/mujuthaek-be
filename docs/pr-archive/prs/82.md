### 무엇을

주소 사전에서 못 찾은 공고 주소(지번 주소, 건물명이 붙은 주소 등)를 도로명주소 검색 API로 찾는 **클라이언트만** 만들어요 (area 3-2 앞부분). 받은 칸으로 주소 사전에서 다시 찾는 연결은 사전 찾기(3-1, [#60](60.md)·[#75](75.md) 머지 뒤) 다음 PR에서 해요.

#### 클라이언트 (`area.geocode.JusoSearchClient`)
- 요청: `confmKey`, `keyword`, `currentPage=1`, `countPerPage=10`, `resultType=json`. **승인키가 URL에 남지 않게 POST 폼**으로 보내요(예외 메시지·로그에 URL이 찍혀도 키가 안 나가게). 로그엔 오류 코드만
- 응답 `results.juso[]`의 `admCd`(법정동코드 10자리), `rn`, `udrtYn`, `buldMnnm`, `buldSlno`, `rnMgtSn`, `bdMgtSn`, `siNm`·`sggNm`·`emdNm`, `jibunAddr`, `roadAddr` → `JusoResult` (`sigunguCode()` = admCd 앞 5자리)
- 결과 `SearchOutcome`:
  | 결과 | 언제 | 재시도 |
  | --- | --- | --- |
  | `Found` / `NotFound` | 정상(`errorCode` 0) | — |
  | `Rejected(code)` | 검색어 문제 E0005~E0013·E0015 (너무 짧음·너무 김·범위 초과 등) — 좌표 찾기에선 NOT_FOUND | 안 함 |
  | `Failed(KEY_REJECTED)` | 승인키 오류·만료 E0001·E0014 | 안 함 |
  | `Failed(UNAVAILABLE)` | 시스템 오류 -999·HTTP 5xx·연결 실패 → 2번 다시(0.5초·1초 뒤) 뒤에도 실패, HTTP 4xx는 바로 — 좌표 찾기에선 API_ERROR | 2번 |
  | `Failed(NO_KEY)` / `Failed(RATE_LIMITED)` | 키 없음 / 하루 한도 넘음 — 부르지 않음 | — |

#### 검색어 거르기
공식 안내에서 쓸 수 없다는 특수문자(`% = > < [ ]`)와 SQL 예약어(OR·SELECT·INSERT·DELETE·UPDATE·CREATE·DROP·EXEC·UNION·FETCH·DECLARE·TRUNCATE)를 지우고 공백을 하나로. 예약어는 **낱말 하나일 때만** 지워요 — 공식 예제처럼 글자 일부까지 지우면 "TOWER" 같은 건물명이 망가져요. 거르고 비면 부르지 않음.

#### 후보 고르기 (`JusoCandidates.pick`)
검색 API는 비슷한 주소도 줘요. 실제로 구를 잘못 적은 `부산광역시 동구 초량상로 1-2`를 보내면 **동구의 초량상로35번길·105번길 1-2 두 개만** 오고 진짜 주소(중구 `2611010100`)는 없어요. `중구`로 보내면 진짜 하나만 와요. 그래서 아는 만큼 좁혀요: 도로명(공백 무시) → 건물번호 → 법정동코드 → 시군구. 맞는 게 없으면 그 조건은 건너뛰고, 마지막에 하나(또는 모두 같은 건물 출입구)일 때만 골라요. 정해지지 않으면 고르지 않아요 — 엉뚱한 단지에 좌표를 주는 것보다 못 찾는 게 나아서요. 위 동구 예처럼 비슷한 도로명만 있으면 고르지 않고, 도로명·번호가 똑같은 결과가 있으면 공고의 구가 틀려도 그것을 골라요(시군구는 경계 검사가 봐요).

#### 호출 수 제한
- 초당(`per-second`, 기본 5): 넘으면 가장 오래된 호출에서 1초가 지날 때까지 기다림
- 하루(`per-day`, 기본 10000, 한국 시각 자정 초기화): 넘으면 그날은 `RATE_LIMITED`
- 재시도도 한 번으로 셈. 앱 하나 안에서만 세서, api를 여러 대 띄우면 나눠서 설정

#### 설정
```yaml
mujuthaek.area.juso-search:
  base-url: https://business.juso.go.kr/addrlink/addrLinkApi.do
  api-key: ${JUSO_SEARCH_API_KEY:}   # 비면 부르지 않음 (주소 사전으로만)
  per-second: 5
  per-day: 10000
  retries: 2
  timeout: 5s
```
`infra/.env.example`에 빈 `JUSO_SEARCH_API_KEY=` 줄 추가.

### 테스트
가짜 서버(`MockRestServiceServer` — spring-boot-starter-test에 이미 있어서 새 의존성 없음)로: 결과 1개(폼에 키·검색어, URL엔 키 없음) / 여러 개 / 0개 / 검색어 오류(재시도 없음) / 키 오류 / 시스템 오류 2번 재시도 뒤 실패 / 5xx 뒤 성공 / 4xx / 키 없음(부르지 않음) / 하루 한도(재시도 포함) / 검색어 거르기 / 후보 고르기 / 초당 기다림·한국 자정 초기화. 진짜 키 없이 돌아요.

실제 API로 한 번 확인(키는 출력 안 함): POST 폼이 받아지고, `동구 초량상로 1-2` → 비슷한 도로 2개(진짜 없음), `중구 초량상로 1-2` → 1개(`2611010100`), `서울` → E0006, `금천구 시흥대로 377` → `admCd 1154510200`, `rn 시흥대로`, 377-0.
