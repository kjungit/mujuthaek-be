### 왜
사업공간·사업 지원이 거의 다 "확인 필요"로 나왔어요.
- 판정 엔진(frame)은 나이를 생년월일로만 판정하는데, 프론트는 정확한 날 대신 출생 연월만 보내요 (구간만 보내는 원칙) → 나이 조건이 늘 확인 필요
- 질문형 조건(ASK)은 엔진이 답(`answers`)을 받을 수 있지만 모든 호출이 빈 맵이라 답할 방법이 없었어요 → 사업공간은 지원 가능이 나올 수 없음

### 바뀐 점
- **출생 연월로 나이 판정**
  - `JudgmentApplicantRequest.birthMonth`(예: `1997-03`) → frame `Applicant.birthMonth` (기존 위치 생성자는 그대로 두고 보조 생성자 추가)
  - `PersonRules.age`: 생년월일이 없고 연월이 있으면 그 달 첫날·마지막 날 둘 다 같은 결과일 때만 충족/불충족, 기준일이 생일 달이면 확인 필요(생년월일을 물어요). 주거 엔진의 `Bands.ages`·`ageWithin`을 같이 써요
- **질문 답 받기**
  - `SpaceEvaluateRequest.answers`(질문 id → YES·NO) → `POST /spaces/{id}/evaluate`, `/supports/{id}/evaluate` → `MatchQueryService.judgeOne` → 엔진
  - 목록 판정은 그대로(답 없음). 답은 저장·로그 안 함

### 확인
- 테스트: `RulesTest`(출생 연월: 결정·경계 달 확인 필요), `MatchQueryServiceTest`(질문 답이 결과에 실림), eligibility 전체 통과
- 로컬: 청양군 누구나가게 나이 조건 — 연월 없음 UNKNOWN, 1997-03 MET, 1980-03 NOT_MET / 관광기업지원센터 제외 질문 YES → 지원 불가
