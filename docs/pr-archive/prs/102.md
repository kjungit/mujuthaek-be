### 무엇

홈 화면 API `POST /api/v1/home/summary`를 만들었어요. 맞춤 목록(`POST /notices/search`)과 **같은 판정**(`NoticeSearchService.judgeAll`)을 한 번 돌리고, 홈 카드에 쓰는 값만 골라요.

- **요청:** `{ filters, applicant }`. 필터는 맞춤 목록과 같아요(찾아볼 지역 등). 판정 입력은 구간 값이에요([#101](101.md)).
- **응답:** 판정 입력은 저장하지 않고, 응답은 `no-store`예요.
  - `homes`: 지원 가능·확인 필요·지원 불가 수, `newThisWeek`(최근 7일 공고), `closingSoon`(접수 중 7일 안 마감)
  - `news`: 공고일 최신순 4개
  - `deadlines`: 접수 중 14일 안 마감, 마감 임박순 3개
  - `bestArea`: 확인 필요 이상 공고 중 생활권 총점이 가장 높은 곳(없으면 null)
  - 지원 불가 공고는 소식·마감 목록과 이번 주·마감 임박 개수에서 빼요.
- 맞춤 목록 항목에 `postedOn`(공고일)을 더했어요.
- 혜택 요약·추천 혜택은 benefit 모듈 데이터가 아직 없어서 넣지 않았어요. 직장 통근 시간도 받지 않기로 해서 없어요.

[#101](101.md)(`feat/applicant-bands`) 위에 올렸어요. #101에는 이 작업을 하다가 찾은 두 가지 수정도 커밋으로 더했어요.
- 소득 % 구간마다 기준 연도(`year`)를 받아요. 고시 값 표의 도시근로자 소득이 2025년까지라, 2026년 기준만으로는 도시근로자 기준 공고가 항상 확인 필요였어요.
- 도시근로자 가구원수별 표와 가구당 평균(공공분양) 표가 섞여 읽히던 것을 따로 읽어요.
