### 왜
사업공간 화면의 "사업 지원"(창업지원 사업) 칸이 목업이에요. 판정 엔진(`startup-support-judgment.v1`, `MatchQueryService.matchStartupSupport`)은 있었지만 HTTP로 열린 곳이 없었어요.

API 설계는 혜택 API(`/benefits/search`, `fields: ["STARTUP"]`)였지만, 창업지원은 혜택 표(`benefit.benefits`)가 아니라 판정 틀(`notice.policy_judgments`)로만 들어와서 사업공간([#128](128.md))과 같은 모양으로 따로 열어요.

### API
#### `POST /api/v1/supports/search` 맞춤 목록
- 요청: `filters.subFields`(FUND · LOAN · TAX), `filters.regionCodes`(시도 2자리·시군구 5자리), `applicant`(판정 엔진 입력, 사업 입력은 `business`), `sort`(RECOMMENDED · DEADLINE), `includeIneligible`, `cursor`, `size`
- 응답: `counts`, `subFieldCounts`, `items`(`source` KSTARTUP·BIZINFO, `subField`, 기간·D-day·상태, `overall`, `groups`, `missingInputs`, `detailUrl`), `nextCursor`, `hasNext`
- 지원 종류는 판정 틀에 없어서 이름으로 정해요 (융자·대출·보증·정책자금 → LOAN, 세액·감면 → TAX, 나머지 FUND)
- 같은 사업이 K-Startup·기업마당에 같이 있으면 이름(글자·숫자)이 같은 것 중 K-Startup만

#### `POST /api/v1/supports/{id}/evaluate` 사업 하나의 판정
- 응답: 출처·종류·제목·원문·기간·D-day·상태·지역·`judgment`. 사업 상세 API가 없어서 화면은 이 응답으로 상세를 보여줘요
- 열린 사업이 아니면 404 `NOTICE_NOT_FOUND`

### 바뀐 점
- `MatchQueryService`: `judgeStartupSupportAll`, `judgeStartupSupport(id)`. 하나 판정은 사업공간과 같이 `judgeOne`으로 (`SpaceJudgment` → `OneJudgment`)
- `SupportSearchService`, `SupportController`, 요청·응답 DTO. 지역 거르기·출처·상태는 `SpaceSearchService`를 같이 써요
- 테스트: `SupportSearchServiceTest`(종류 나누기·같은 사업 하나만), `MatchQueryServiceTest`에 지원사업 목록·하나 판정

### 남은 것
- 이름이 다른 같은 사업(예: K-Startup「<2026년 시제품 고도화 바우처…>」 · 기업마당「[충북] 청주시 2026년 시제품 고도화 바우처…」)은 아직 둘 다 나와요
- 지원 금액은 판정 틀에 없어서 응답에 없어요
