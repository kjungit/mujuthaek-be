### 무엇을

프론트를 실제 API에 붙이기 시작하면서, CORS 허용 주소를 `FRONTEND_URL` 하나에서 여러 개로 늘려요.

- `app.cors-origins: ${CORS_ORIGINS:}` 추가 (쉼표로 여러 개)
- 허용 주소 = `frontend-url` + `cors-origins` (빈 칸·앞뒤 공백·중복 제외)
- 로그인 뒤 돌아갈 주소는 그대로 `frontend-url`

예) 로컬에서 프론트를 3200 포트로 띄울 때 `CORS_ORIGINS=http://localhost:3200`

### 확인

- `./gradlew spotlessApply check` 통과 (`LoginPropertiesTest` 추가)
- 로컬 실행 후 preflight: `http://localhost:3000`·`http://localhost:3200` → 허용, 다른 주소 → 403
- 프론트(`NEXT_PUBLIC_USE_MOCKS=false`)에서 `GET /api/v1/regions` 200, 조건 입력·내 집 지역 필터 동작
