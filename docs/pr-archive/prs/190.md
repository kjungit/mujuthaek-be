### 왜
성능 테스트 동안 EC2 CPU(특히 t3 크레딧이 바닥날 때 오르는 steal)와 컨테이너별 CPU·메모리를 봐야 해요. CloudWatch EC2 기본 모니터링은 5분 단위라 짧은 테스트(스파이크 4분 등)에선 거의 안 보여요.

### 바꾼 것 (`infra/deploy/compose.prod.yml`)
- `node-exporter`(`127.0.0.1:9100`), `cadvisor`(`127.0.0.1:9101`) 추가
- **compose profile `perf`**: `deploy.sh`는 띄우지 않아요. 테스트 날에만 켜고 끝나면 꺼요
  - 켜기: `docker compose -f compose.prod.yml --env-file .env --env-file versions.env --profile perf up -d node-exporter cadvisor`
- 서버 자원을 덜 쓰게: 메모리 제한 64m·150m, cAdvisor는 쓰지 않는 지표(percpu, disk, tcp 등) 끄고 15초 간격

### 확인
- `docker compose --profile perf config`로 서비스 목록 확인, 이미지 태그 존재 확인
- 서버 적용은 다음 릴리즈에서 compose 파일이 올라간 뒤 켜서 확인해요
