### 왜
- 기관 9곳이 같이 쓰는 부분을 먼저 넣고 테스트로 고정해요. 기관별 수집기는 "어떤 주소를 열어 무엇을 꺼내나"만 구현하면 돼요.
- **robots.txt 캐시를 프로세스 전체로 뒀어요.** 스케줄러가 회차마다 클라이언트를 새로 만들어서, 캐시가 클라이언트 안에 있으면 매시 robots.txt를 다시 받아요. 이제 기관마다 하루 한 번만 받아요.

### 알아둘 것
- collector의 ruff 줄 길이는 160이에요(이 프로젝트 `pyproject.toml` 설정). 저장소 기본은 120이에요.
