### 무엇을

소셜 로그인(카카오·네이버·구글)만 쓰기로 하면서 프론트를 맞췄고, 로그인 뒤 돌아갈 곳을 백엔드에서 정해 줘요.

- 로그인 성공: `{FRONTEND_URL}/` → `{FRONTEND_URL}/auth/callback`
- 이번 로그인에서 **처음 가입**했으면 `?new=1`
  - 프론트 콜백은 `POST /api/auth/refresh`로 access token을 받고, `new=1`이면 약관 동의(가입 마무리) 화면, 아니면 홈으로 보내요
- `SocialLoginService.loginOrJoin(profile)` → `SocialLogin(user, joined)`. 기존 `login(profile)`은 그대로 (`loginOrJoin(...).user()`)
- 처음 가입 여부는 콜백 요청 속성으로 `SocialOAuth2UserService` → `LoginSuccessHandler`에 넘겨요 (같은 콜백 요청 안)

탈퇴 쪽 돌아갈 주소(`/mypage?withdraw=…`, `/withdrawn`)는 프론트 내 정보 연결 때 같이 맞출게요.

### 확인

- `./gradlew spotlessApply check` 통과
  - `SocialLoginServiceTest.joinedOnlyOnFirstLogin`: 첫 로그인만 joined
  - `SecurityIntegrationTest.firstLoginGoesToCallbackWithNewFlag`: 첫 로그인 → `/auth/callback?new=1`, 다음 → `/auth/callback`
  - 기존 `loginSuccessSetsRefreshCookieAndGoesToFrontend` 주소를 `/auth/callback`으로
